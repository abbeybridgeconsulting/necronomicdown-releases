# Necronomicdown releases

Public macOS beta releases of Necronomicdown are published in this repository's [Releases](https://github.com/abbeybridgeconsulting/necronomicdown-releases/releases) section.

**Maintainers: [How to publish a beta](RELEASING.md)** — version bumps, building, checksums, testing, VirusTotal and GitHub publishing.

Necronomicdown is currently an ad hoc signed, unnotarised app for Apple Silicon and macOS 15 or later. macOS may block its first launch; after trying to open it, use System Settings → Privacy & Security → Open Anyway if you trust the download.
